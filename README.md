# Repures Demo

This repository contains the **demo version of the Repures platform UI** used for product demonstrations, investor presentations, and onboarding walkthroughs.

The demo application shows the user interface with **mock data** and does not connect to the production backend.

## Purpose

- Product demonstrations
- UI walkthroughs
- Sales presentations
- Investor demos

## Features

- Dashboard preview
- Sample review analytics
- Example review responses
- Mock alerts and notifications

## Tech Stack

- Frontend framework used in the main product (e.g., Next.js / React)
- Static hosting

## Deployment

The demo is deployed as a static application

Domain example: demo.repures.com


## Important Notes

- The demo contains **no real customer data**
- All content is **static or mocked**

## Related Repositories

- `repures-web-app` – Main SaaS frontend
- `repures-backend` – Backend services
